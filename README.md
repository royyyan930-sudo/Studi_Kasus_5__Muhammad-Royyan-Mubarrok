2. Menentukan harga kamar

Bagian ini menggunakan percabangan untuk menentukan tarif:

Standard = Rp200.000 per malam

Deluxe = Rp350.000 per malam

3. Menghitung total biaya

Harga kamar dikalikan dengan jumlah malam menginap.

4. Mengembalikan hasil

return digunakan untuk mengembalikan nilai total biaya dari function.

5. Memasukkan data

Program meminta pengguna memasukkan:

jenis kamar

tanggal check-in

tanggal check-out

int() digunakan agar tanggal menjadi angka sehingga bisa dihitung.

6. Menghitung lama menginap

Tanggal check-out dikurangi tanggal check-in.

7. Memanggil function

Program memanggil function hitung_biaya() dengan memasukkan:

jenis_kamar

lama_menginap

Hasilnya disimpan ke dalam total_biaya.

8. Menampilkan hasil

Bagian ini menampilkan data pemesanan dan total biaya kepada pengguna.
